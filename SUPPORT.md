# Getting Support

Thanks for using `combolite-core`. Here's where to go:

| Need | Where |
|---|---|
| **How-to / usage questions** | Read the [README](README.md), [`docs/FAQ.md`](docs/FAQ.md), the user manual (`docs/user-manual.html`), and the CMBQL manual (`docs/cmbql-manual.html`). |
| **API reference** | `docs/CRUD_REFERENCE.md` and `docs/api-usage.html`. |
| **On-disk / query spec** | `docs/spec/` (§01–§15). |
| **Bug reports** | Open an issue with the **Bug report** template. |
| **Feature requests** | Open an issue with the **Feature request** template. |
| **Security vulnerabilities** | **Do not** open a public issue — use the private flow in [`SECURITY.md`](SECURITY.md). |
| **Contributing** | [`CONTRIBUTING.md`](CONTRIBUTING.md). |

Please search existing issues before filing a new one. This is an open-source project maintained on
a best-effort basis; response times are not guaranteed, but every report is triaged.
